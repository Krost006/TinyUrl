## Цель

Создать сервис для сокращения ссылок и инфраструктуру для его поддержания

## Функциональныйе требования

* Регистрация, авторизация и аутентификация пользователей
* Сокращение исходной ссылки 
* Просмотр активных ссылок
* Удаление активных ссылок
* Просмотр статистики посещения ссылки
* Сервис поддерживает редирект по сокращённым ссылкам

## Нефункциональные требования

* Длина сокращённой ссылки равна 8 символам
* Сокращённые ссылки должны выдаваться так, чтобы оптимизировать нагрузку на сервер
* Сервис доступен только авторизированным пользователям
* Предоставляется места только для 10 ссылок

## Модель данных

### Пользователь(user)

Структура, содержащяя информацию о пользователе
* ID
* Username
* Password
* Email

### Ссылка(href)

Содержит информацию о сокращённой ссылке
* ID
* URL - сокращённая ссылка
* LongURL - длинная ссылка

###  Связь пользователя и ссылки(userhref)

Связывает пользователя с ссылкой
* ID
* UserID
* HrefID

### Переход по ссылке(click)

Фиксирует переход по ссылке и информацию о переходившем. Удаляется при изменении длинного адреса ссылки или удалении

* ID
* HrefID
* IP
* Country
* Time
